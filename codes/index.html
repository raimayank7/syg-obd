All codes

450 generic OBD-II codes in 57 groups. Type a code or a word to filter, then open a group for the full explanation.

How this list is arranged

The codes are grouped by the system they belong to, in the order the standard numbers them: fuel and air first, then ignition and misfires, emission controls, speed and idle control, the engine computer and its outputs, the transmission, and last the network codes that begin with U. Inside a group the codes run in number order, so neighbours in the list are usually neighbours in the car: the same sensor on another cylinder, or the same circuit reading too high and too low. Each line gives the short official meaning in plain words. Open the group for what the fault feels like when driving, how serious it is, the usual causes and what to check first.

If you only have part of a code

Type the first characters, such as P03, in the filter box to see the whole family. Typing a word such as "oxygen", "misfire" or "coolant" finds every code whose meaning mentions it.
