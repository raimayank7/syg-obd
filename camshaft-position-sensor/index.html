P0340 to P0349

Camshaft position sensor

Fault codes P0340 to P0349 explained in plain words: what the car is telling you, how serious it is and what to check first.

How serious: MediumDrive gently and have it repaired soon. Leaving it can lead to bigger faults or higher fuel use.

What it means

The camshaft position sensor tells the computer which cylinder is on its firing stroke, so injectors and coils fire in the right order. Many engines can still run on the crankshaft signal alone, but start slowly and run less smoothly.

Bank 1 is the side of the engine that has cylinder 1. Sensor 1 is before the catalytic converter and sensor 2 is after it. More terms explained.

What you may notice

  • Long cranking before the engine starts
  • Rough running or hesitation
  • Occasional stalling
  • Sometimes no symptom

Common causes

Most likely first:

  • A failed sensor
  • Oil leaking into the connector
  • Damaged wiring
  • A stretched timing chain (if the reading is "out of range")

What to check first

  • Check the sensor plug for oil
  • If P0016 to P0019 are stored too, the timing chain or belt should be checked first

Have a mechanic confirm. A fault code tells you which system reported a problem, not which part has failed. The same code can have several causes, and they differ between car models. Use this page to understand the code, then have a qualified mechanic test the car before any part is replaced.

After the repair

Once the cause is fixed, the code can be cleared with a scan tool, or the warning light goes out by itself after several trips without the fault. Clearing a code without fixing the cause only hides it for a while. More about clearing codes.
